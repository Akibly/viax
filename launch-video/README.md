# ViaX launch motion graphic

An animated 1920×1080, 30 fps launch video for ViaX. It follows the product story from a student's uploaded material to grounded concepts, viva practice, cited feedback, and review. Visual study content in the animation is illustrative; it does not represent a real student's data.

## Preview

```sh
npm install
npm run dev -- --no-open
```

Open the local URL printed by Remotion Studio and choose **ViaXLaunch**.

## Export

```sh
npx remotion render src/index.ts ViaXLaunch outputs/viax-launch.mp4
```
